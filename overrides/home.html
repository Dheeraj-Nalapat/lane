Run every version of your project — at once.

Give each git worktree (or project) its own isolated, port-conflict-free stack at a friendly *.localhost URL — so you and your AI agents can spin up and test many versions in parallel, and ship faster.

Get started Install GitHub 
curl -sSL https://github.com/Dheeraj-Nalapat/lane/releases/latest/download/install.sh | sh

Linux & macOS · other ways to install →

No port conflicts

Stacks publish zero host ports — a shared proxy routes by hostname, so any number run side by side.

Parallel by design

N git worktrees → N live stacks at distinct <slug>.localhost URLs, all up at the same time.

Built for agents

One agent per worktree: lane up --wait --json → test → lane down. Race-safe, machine-readable.

Let your agents test in parallel

Reviewing three pull requests? Pit two implementations of the same feature against each other? Running a whole fleet of coding agents? Check out each version into its own worktree and bring it up — lane keeps every stack isolated, so agents test concurrently instead of waiting in line for a port. More parallelism, faster iteration.
