lane

Parallel, port-conflict-free dev stacks.

Run many projects — and many git worktrees of one project — at once. Each gets an isolated stack at a friendly *.localhost URL.

Get started GitHub 
brew install Dheeraj-Nalapat/lane/lane

Run many at once

No host ports published — a shared proxy routes by hostname, so stacks never collide.

Friendly URLs

Each stack at <slug>.localhost; worktrees get distinct slugs automatically.

Agent-drivable

lane up --wait --json — machine-readable, race-safe parallel testing for Claude/Cursor.

lane up --wait --json
